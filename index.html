How to try a project

Most experiences use the same HTTPS URL on a computer, a phone, and a VR headset. Wing Chun and the Anatomy XR Collection are 3D viewers in the browser (no headset session).

  1. Desktop or laptop

    Open a project in Chrome or Edge. Move with the keys shown on each project page.

  2. Phone or tablet

    Use Chrome. On-screen sticks and buttons appear where a project supports them.

  3. VR headset

    Open the same link in Quest Browser (or another WebXR browser) and tap Enter VR.
